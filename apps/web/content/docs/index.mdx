Emend is an open-source, MIT-licensed AI editing layer for Tiptap and
ProseMirror. It combines a provider-neutral runtime with editable Shadcn
registry components, while keeping generated edits separate from the live
document until the person writing accepts them.

<Callout type="warn" title="Pre-release documentation">
  The registry is ready, but `@emend/ai` is not published to npm yet. Commands
  in these docs describe the verified preview flow and will work publicly after
  the package is released.
</Callout>

## What Emend gives you

- **Three AI surfaces:** a selection-aware Bubble Menu, a Composer for focused
  prompts, and a document-aware AI Assistant.
- **Reviewable changes:** Ask returns an answer. Edit creates a proposal that
  can be accepted, rejected, or left untouched.
- **Provider-neutral infrastructure:** your server route chooses the model,
  provider, authentication, rate limits, and logging.
- **Two ways to start:** add one surface to an editor you already own, or copy a
  complete editor starter into your app.

## Choose an integration path

| Starting point         | What you keep                                     | What Emend adds                                     |
| ---------------------- | ------------------------------------------------- | --------------------------------------------------- |
| Existing Tiptap editor | Your schema, extensions, toolbar, and persistence | One or more AI surfaces and the review runtime      |
| Emend editor starter   | Full ownership of the copied component source     | A complete editor with your choice of AI experience |

## How Emend is distributed

| Part          | Distribution        | Purpose                                                          |
| ------------- | ------------------- | ---------------------------------------------------------------- |
| `@emend/ai`   | npm package preview | Protocol, controller, transports, React, Tiptap, and server APIs |
| UI components | Shadcn registry     | Bubble Menu, Composer, AI Assistant, and editor starters         |
| Server recipe | Shadcn registry     | Consumer-owned Vercel AI Gateway route                           |

### The editing flow

1. Your Tiptap editor captures a target and any read-only context.
2. Emend sends Markdown through a transport to your server route.
3. Ask displays an answer; Edit prepares a proposal and temporary preview.
4. Accept applies one undoable Tiptap change. Reject leaves the document as it
   was.

## What stays yours

The editor, copied component source, server route, provider credentials,
authentication, persistence, and deployment remain inside your application.
Emend does not replace your product's permissions, content model, or backend.
