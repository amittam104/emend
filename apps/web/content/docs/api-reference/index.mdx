This section lists what the `@emend/ai` package gives you. If you use the
ready-made AI components, you only need a few of these. Read on if you want to
build your own AI UI or server route.

## Where to import from

The package is split into parts, so browser code and server code only load
what they need.

| Import from           | What it has                                                      |
| --------------------- | ---------------------------------------------------------------- |
| `@emend/ai/react`     | `useEditorAi`, the React hook for running AI requests            |
| `@emend/ai/tiptap`    | The `EmendAi` Tiptap extension, plus preview and apply helpers   |
| `@emend/ai/transport` | Transports that send requests from the browser, including a mock |
| `@emend/ai/server`    | The server route handler and a mock AI for testing               |
| `@emend/ai/protocol`  | Types for requests, streamed answers, actions, and errors        |
| `@emend/ai`           | The most common exports from all of the above                    |
