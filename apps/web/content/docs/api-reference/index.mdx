The Emend runtime is split into focused entry points so client components,
Tiptap integrations, and server routes import only the layer they use.

<Callout type="warn" title="Preview API">
  `@emend/ai` is not published to npm yet. This reference describes the API in
  the current repository and the packed package verified in consumer fixtures.
</Callout>

## Entry points

| Entry point           | Primary use                                              |
| --------------------- | -------------------------------------------------------- |
| `@emend/ai/react`     | React session lifecycle with `useEditorAi`               |
| `@emend/ai/tiptap`    | Tiptap extension, adapter, capture, preview, and apply   |
| `@emend/ai/transport` | Fetch/SSE and deterministic mock transports              |
| `@emend/ai/server`    | Web Platform handler, SSE helpers, and mock generation   |
| `@emend/ai/protocol`  | Requests, stream events, actions, controller, and errors |
| `@emend/ai`           | Common exports from the public runtime                   |
