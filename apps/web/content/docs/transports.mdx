---
title: Transports
description: How AI components send requests to your server and get answers back.
---

A **transport** is how an AI component sends a request and gets the answer
back. Most apps use the fetch transport, which sends requests to a URL on your
server. You create one and pass it to your component as the `transport` prop.

The transport does not care which AI provider you use. It only moves requests
and answers.

## Which one to use

| Option                                  | Use it for                                        | Network |
| --------------------------------------- | ------------------------------------------------- | ------- |
| `createFetchTransport`                  | Your real app. Sends requests to your server route | Yes     |
| `createMockTransport`                   | Demos and building UI without a server or API key  | No      |
| `mockGenerate` + `createFetchTransport` | Testing your server route without calling a model  | Yes     |
| Custom `EmendTransport`                 | WebSockets, workers, queues, or anything else      | Depends |

## Fetch transport (most apps)

```ts
import { createFetchTransport } from "@emend/ai/transport"

const transport = createFetchTransport({
  url: "/api/editor-ai",
})
```

It sends each request to your URL as a `POST`, and reads the answer as it
streams back. If the server returns an error, such as `401` or `429`, it turns
it into an [emend error](/docs/api-reference/error-codes) your UI can show.

To add headers or change other options, see
[`createFetchTransport`](/docs/api-reference/create-fetch-transport).

## Mock transport (no server needed)

```ts
import { createMockTransport } from "@emend/ai/transport"

const transport = createMockTransport({
  delayMs: 30,
})
```

It returns fake answers that match the action, so you can build and test your
UI without a server or API key. Set `failAfterDeltas` to fake an error partway
through an answer.

## Build your own transport

```ts
import type { EmendTransport } from "@emend/ai"

const transport: EmendTransport = {
  async *run(request, signal) {
    signal.throwIfAborted()

    for await (const event of readEvents(request, signal)) {
      yield event
    }
  },
}
```

Your transport must:

- stop when `signal` is aborted (for example, when the user clicks Stop), so
  you do not keep paying for an answer nobody will see;
- send back events with the same protocol version and request ID as the
  request. Events that do not match are ignored.

Next, see [Vercel AI Gateway](/docs/vercel-ai-gateway) for a ready-made server
route, or [`createEmendAiHandler`](/docs/api-reference/create-emend-ai-handler)
to build your own.
