Use this guide if your app already has a Tiptap editor. You keep your editor
as it is and add the Bubble Menu to it. The same steps work for the Composer
and the AI Assistant.

<include>../partials/nextjs-only.mdx</include>

## Before you start

Make sure your project has everything below before you add AI to your editor.

- A component that creates your Tiptap editor (with `"use client"` at the top)
- Tiptap `3.31.4`, including `@tiptap/markdown`
- The `@emend` registry added to `components.json` (see
  [Installation](/docs/installation))
- A server route for AI requests, such as `/api/editor-ai`. The
  [last section](#connect-the-server-route) shows how to add one.

Install or align your editor dependencies before adding Emend. The example
below uses StarterKit; keep your own extensions if you already have an editor.

```npm
npm install @tiptap/core@3.31.4 @tiptap/react@3.31.4 @tiptap/pm@3.31.4 @tiptap/starter-kit@3.31.4 @tiptap/markdown@3.31.4
```

## Add the Bubble Menu

You only change one file: the component that creates your editor. Lines
marked with **+** are the ones to add.

<Steps>
<Step>

### Install the component

```npm
npx shadcn@latest add @emend/ai-bubble-menu
```

This copies the Bubble Menu into `components/emend/ai-bubble-menu`.

</Step>
<Step>

### Add the emend extension

Add `EmendAi` and `Markdown` to your editor's extensions. `EmendAi` lets the AI
components work with your editor. `Markdown` lets emend send your text to the
AI as Markdown and turn the answer back into editor content.

```tsx title="components/document-editor.tsx"
"use client"

import { EmendAi } from "@emend/ai/tiptap" // [!code ++]
import { Markdown } from "@tiptap/markdown" // [!code ++]
import { EditorContent, useEditor } from "@tiptap/react"
import StarterKit from "@tiptap/starter-kit"

export function DocumentEditor() {
  const editor = useEditor({
    immediatelyRender: false,
    extensions: [StarterKit, Markdown, EmendAi], // [!code ++]
    content: "<p>Select this sentence and ask emend to improve it.</p>",
  })

  if (!editor) return null

  return (
    <div className="relative">
      <EditorContent editor={editor} />
    </div>
  )
}
```

</Step>
<Step>

### Show the Bubble Menu

Create a transport (it tells the component which URL to send AI requests to),
then render the Bubble Menu with your `editor`.

```tsx title="components/document-editor.tsx"
"use client"

import { EmendAi } from "@emend/ai/tiptap"
import { createFetchTransport } from "@emend/ai/transport" // [!code ++]
import { Markdown } from "@tiptap/markdown"
import { EditorContent, useEditor } from "@tiptap/react"
import StarterKit from "@tiptap/starter-kit"
import { AiBubbleMenu } from "@/components/emend/ai-bubble-menu" // [!code ++]

const transport = createFetchTransport({ url: "/api/editor-ai" }) // [!code ++]

export function DocumentEditor() {
  const editor = useEditor({
    immediatelyRender: false,
    extensions: [StarterKit, Markdown, EmendAi],
    content: "<p>Select this sentence and ask emend to improve it.</p>",
  })

  if (!editor) return null

  return (
    <div className="relative">
      <EditorContent editor={editor} />
      {/* [!code ++] */}
      <AiBubbleMenu editor={editor} transport={transport} />
    </div>
  )
}
```

Pass the same `editor` you already render. Do not create a second one for the
AI. The Bubble Menu needs your real editor to read the selected text and show
its preview there.

</Step>
</Steps>

## Use more than one AI component

For a Bubble Menu and Composer on the same editor, create one `useEditorAi`
session and pass it to their View components. This keeps their requests,
preview, and review controls in sync.

```tsx
import { useEditorAi } from "@emend/ai/react"
import { AiBubbleMenuView } from "@/components/emend/ai-bubble-menu"
import { AiComposerView } from "@/components/emend/ai-composer"

// Inside DocumentEditor, before the early return:
const session = useEditorAi({ editor, transport, previewMode: "inline" })

// Inside your editor wrapper:
<AiBubbleMenuView editor={editor} session={session} />
<AiComposerView editor={editor} session={session} />
```

Install both registry items before using this example. Use the standalone
`AiBubbleMenu` or `AiComposer` wrapper when you only need one surface.

## Try it

1. Select some text in your editor. The Bubble Menu opens next to it.
2. Pick an action such as **Improve**, or type what you want in **Describe
   edits**.
3. The suggested change shows up as a preview. Your text has not changed yet.
4. Click **Accept** to apply it, or **Reject** to throw it away.

If you accept a change, you can undo it like any other edit
(<kbd>Cmd</kbd>+<kbd>Z</kbd> on Mac, <kbd>Ctrl</kbd>+<kbd>Z</kbd> on Windows and Linux).

Next, see [AI Bubble Menu](/docs/ai-bubble-menu) for its options. If you would
rather start with a complete editor, see the
[Editor Starter](/docs/emend-editor-starter).
