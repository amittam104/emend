emend comes in two parts:

- **The AI components** (Bubble Menu, Composer, AI Assistant). The Shadcn CLI
  copies their source code into your project, so you can edit them like your
  own files.
- **The `@emend/ai` package.** An npm package that does the work behind the
  components: it talks to your server, streams the AI response, and applies
  changes to your editor.

<Callout type="warn" title="Not on npm yet">
  `@emend/ai` is not published to npm yet, so the install commands below will
  not work until it is released. We test the same steps with a local build of
  the package.
</Callout>

## Before you start

Make sure your project has everything below before you install emend.

- Next.js with the App Router, and React 19
- Tiptap `3.31.4` (all `@tiptap/*` packages on the same version)
- Shadcn set up with Tailwind CSS 4 (run `npx shadcn@latest init` if you have
  not)
- Node.js `24.19.0` or later
- A server route that calls the AI model. You add this later with
  [one command](/docs/vercel-ai-gateway).

## Set up your project

<Steps>
<Step>

### Tell Shadcn where to find emend

Open the `components.json` file that Shadcn created and add the `@emend`
registry:

```jsonc title="components.json"
{
  "$schema": "https://ui.shadcn.com/schema.json",
  "style": "new-york",
  "tailwind": { "css": "app/globals.css" },
  "registries": { // [!code ++]
    "@emend": "https://getemend.vercel.app/r/{name}.json" // [!code ++]
  } // [!code ++]
}
```

If you are running the emend repository locally, use
`http://127.0.0.1:3000/r/{name}.json` instead.

</Step>
<Step>

### Install the package

Install `@emend/ai` with your package manager:

```npm
npm install @emend/ai@preview
```

</Step>
<Step>

### Add your first component

Start with the Bubble Menu. It is the simplest one:

```npm
npx shadcn@latest add @emend/ai-bubble-menu
```

This copies the component into `components/emend/ai-bubble-menu` and installs
anything it needs. The copied files are yours to change. The AI logic stays in
`@emend/ai`, so you get fixes by updating the package.

</Step>
</Steps>

## What you should see

- A new `components/emend` folder with the component files
- Any Shadcn building blocks it uses (buttons, popovers) in `components/ui`
- `@emend/ai` in your `package.json`
