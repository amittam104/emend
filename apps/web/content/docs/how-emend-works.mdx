---
title: How emend Works
description: What happens between typing a request and seeing the AI's change in your editor.
---

emend is made of four parts. Each one has a single job, so you can change one
without touching the others.

## The four parts

<FlowDiagram />

1. **Your Tiptap editor.** It holds your document, the undo history, and saving.
   emend never takes this over.
2. **The `@emend/ai` package.** It reads the text the AI needs, sends it to your
   server, receives the answer, shows the preview, and applies the change when
   you accept it.
3. **The AI components.** The Bubble Menu, Composer, and AI Assistant. These are
   the buttons and inputs people see. Their source is copied into your app, so
   you can restyle or change them.
4. **Your server route.** It checks who is making the request, calls the AI
   model, and streams the answer back. Your API key stays here.

The components do not include the AI logic themselves. They all use the
`@emend/ai` package. And the package never sees your API key.

## Questions and edits

There are two kinds of requests. In the API they are called **Ask** and
**Edit**.

| Request  | What you get                  | Does it change your document?        |
| -------- | ----------------------------- | ------------------------------------ |
| Question | An answer to read             | Never                                |
| Edit     | A suggested change to review  | Only after you click Accept          |

You do not pick the kind yourself. If you select text and choose an action, it
is an edit. If you just type a question, it is a question.

## What the AI reads and what it changes

emend keeps these two things separate:

- **What the AI reads.** Text it can look at to give a better answer: the
  selected text, the current paragraph, or the whole document.
- **What the AI changes.** The exact piece of text an edit is allowed to
  replace.

Letting the AI read the whole document does not let it change the whole
document. For example, the AI can read the whole page to understand it, but
only rewrite the one sentence you selected.

## What happens during an edit

1. emend saves a snapshot of the text you selected and what the AI can read.
2. Your server sends that to the AI model, and the answer streams back.
3. emend checks that your editor can display the answer.
4. The suggested change shows up as a preview. Your document has not changed
   yet.
5. **Accept** replaces the text with the suggestion. **Reject** removes the
   preview.

If the document changes while a suggestion is showing, the suggestion is out of
date and can no longer be accepted. Moving the cursor or changing the selection
does not count as a change.

## Why the server route is yours

Only your app knows who your users are, which AI provider you pay for, and how
much each user is allowed to use. So the server route lives in your app. emend
gives you a handler to build it and a ready-made
[Vercel AI Gateway recipe](/docs/vercel-ai-gateway). emend does not run a server
for you.
