AI Composer sits below the document. It supports quick writing actions, free
questions, custom edits, and explicit controls for what the model may read and
what an Edit may replace.

## Live demo

Type a question for Ask. Select text and choose a slash or plus-menu action for
Edit, then review the proposal before accepting it.

## Minimal usage

Add `EmendAi` to the same Tiptap editor and pass that editor to the copied
component. Lines marked with **+** are what Emend adds to a standard Tiptap
editor.

```tsx title="components/document-editor.tsx"
"use client"

import { EmendAi } from "@emend/ai/tiptap" // [!code ++]
import { createFetchTransport } from "@emend/ai/transport" // [!code ++]
import { Markdown } from "@tiptap/markdown" // [!code ++]
import { EditorContent, useEditor } from "@tiptap/react"
import StarterKit from "@tiptap/starter-kit"
import { AiComposer } from "@/components/emend/ai-composer" // [!code ++]

const transport = createFetchTransport({ url: "/api/editor-ai" }) // [!code ++]

export function DocumentEditor() {
  const editor = useEditor({
    immediatelyRender: false,
    extensions: [StarterKit, Markdown, EmendAi], // [!code ++]
  })

  if (!editor) return null

  return (
    <>
      <EditorContent editor={editor} />
      {/* [!code ++] */}
      <AiComposer editor={editor} transport={transport} />
    </>
  )
}
```

## Ask, Edit, and scopes

- Plain prompt text is an **Ask** request. It reads the selected context or the
  document and returns an answer without a mutation operation.
- A built-in writing action is an **Edit** request with a predefined target and
  mutation operation.
- A custom Edit can replace the selection, current block, or document, or insert
  at the cursor when the configured policy permits it.
- **Context** is read-only input. **Change** is the exact target an accepted
  proposal may replace.

## Important options

| Prop         | Default         | Purpose                                                    |
| ------------ | --------------- | ---------------------------------------------------------- |
| `editor`     | Required        | The Tiptap editor that owns selection and document state.  |
| `transport`  | Required        | Connects the composer to an Emend-compatible route.        |
| `policy`     | Adaptive scopes | Restricts allowed contexts, mutations, and user overrides. |
| `showReview` | `true`          | Renders Ask results and Edit review beneath the composer.  |
| `className`  | —               | Extends the copied component's outer surface.              |

## Expected result

Ask produces informational Markdown. Edit produces a proposal, preview, and
Accept or Reject controls. Accept stays unavailable when the proposal is stale,
blocked by the schema, or still streaming.
