The Composer is a prompt box that stays under your document. Use it two ways:

- **Edit your text:** Select some text, then pick an action or type what you
  want changed. You see the change before it is applied.
- **Ask a question:** Type a question without picking an action. The answer
  shows up just above the Composer, and your document is not changed.

## Try it

Type a question and send it. Then select some text, open the **+** menu (or type
**/**), and pick an action like **Improve**.

## Before you start

This page assumes your app already has a Tiptap editor and you have completed
[Installation](/docs/installation). If you do not have an editor yet, use the
[Editor Starter](/docs/emend-editor-starter) instead. Its AI Composer
version comes with the Composer already set up.

## Add the Composer

<Steps>
<Step>

### Install the component

```npm
npx shadcn@latest add @emend/ai-composer
```

This copies the Composer into `components/emend/ai-composer` and installs
`@emend/ai` and the Tiptap packages it needs.

</Step>
<Step>

### Add it to your editor

Add the `EmendAi` and `Markdown` extensions to your editor, then render the
Composer with that same editor.

```tsx title="components/document-editor.tsx"
"use client"

import { EmendAi } from "@emend/ai/tiptap" // [!code ++]
import { createFetchTransport } from "@emend/ai/transport" // [!code ++]
import { Markdown } from "@tiptap/markdown" // [!code ++]
import { EditorContent, useEditor } from "@tiptap/react"
import StarterKit from "@tiptap/starter-kit"
import { AiComposer } from "@/components/emend/ai-composer" // [!code ++]

const transport = createFetchTransport({ url: "/api/editor-ai" }) // [!code ++]

export function DocumentEditor() {
  const editor = useEditor({
    immediatelyRender: false,
    extensions: [StarterKit, Markdown, EmendAi], // [!code ++]
    content: "<p>Select this sentence and ask emend to improve it.</p>",
  })

  if (!editor) return null

  return (
    <div className="relative">
      <EditorContent editor={editor} />
      {/* [!code ++] */}
      <AiComposer editor={editor} transport={transport} />
    </div>
  )
}
```

The `transport` tells the Composer which URL to send AI requests to.

</Step>
</Steps>

## Choose what the AI reads and changes

Built-in actions like **Improve** already know what to read and change, so
they do not show any pickers. The pickers only appear next to the prompt when
you write your own request:

- **Read:** What the AI can look at. For example, the selected text, the
  current paragraph, or the whole document. The AI only reads this. It does
  not change it. This picker shows when you pick **Custom instruction** or
  type a question.
- **Change:** What the AI is allowed to replace. You can replace the selection,
  the current block, or the whole document, or insert new text at the cursor.
  This picker shows only when you pick **Custom instruction**, because
  questions never change your document.

Questions read the whole document by default, so you can ask about anything
in it, even with text selected. If your `policy` allows only one option, or
turns off overrides, the matching picker is hidden.

## Props

| Prop         | Default         | Purpose                                                     |
| ------------ | --------------- | ----------------------------------------------------------- |
| `editor`     | Required        | Your Tiptap editor.                                         |
| `transport`  | Required        | Tells the Composer which URL to send AI requests to.        |
| `policy`     | Adaptive scopes | Limits what the AI can read and change.                     |
| `showReview` | `true`          | Shows answers and Accept/Reject buttons above the Composer. |
| `className`  | -               | Adds your own classes to the Composer.                      |

To use the Composer together with another AI component on the same editor,
use `AiComposerView` with a shared session. See
[Use more than one AI component](/docs/existing-tiptap-editor#use-more-than-one-ai-component).

## How it behaves

- **Actions:** **Improve**, **Shorten**, **Longer**, **Fix grammar**, and
  **Custom instruction**. Open the **+** menu or type **/** to pick one. The
  built-in actions need selected text.
- **Questions:** Anything you type without an action is a question. The answer
  shows up just above the Composer, and your document is not changed.
- **Edits:** These show a preview in your document with **Accept** and **Reject**
  buttons. **Accept** is disabled while the AI is still writing, if the text
  changed in the meantime, or if your editor cannot display the result.
