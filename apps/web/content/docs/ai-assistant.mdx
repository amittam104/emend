AI Assistant opens a floating chat above a bottom-right launcher. Each turn can Ask about
the draft or create an Edit proposal, while follow-ups carry the visible
conversation into the next request.

## Live demo

Select the **AI Assistant** launcher in the bottom-right corner. Ask about the
draft, send a follow-up, or select text and choose an Edit action.

## Toolbar launcher variation

If your editor already has a toolbar, you can add an Assistant toggle there as
another way to open the same chat. The floating launcher remains available.

```tsx
<EmendEditorAssistant transport={transport} showToolbarAssistantToggle />
```

## Minimal usage

Use controlled state when another control opens the chat.

```tsx
import { useState } from "react"
import { createFetchTransport } from "@emend/ai/transport"
import type { Editor } from "@tiptap/core"
import { AiAssistant } from "@/components/emend/ai-assistant"

const transport = createFetchTransport({ url: "/api/editor-ai" })

export function DocumentChat({ editor }: { readonly editor: Editor }) {
  const [open, setOpen] = useState(false)

  return (
    <>
      <button type="button" onClick={() => setOpen(true)}>
        Open AI Assistant
      </button>
      <AiAssistant
        editor={editor}
        transport={transport}
        open={open}
        onOpenChange={setOpen}
      />
    </>
  )
}
```

The editor passed to this component must include `EmendAi`. The assistant uses
the shadcn Popover built on Base UI. It stays open while you interact with the
document. Close it with the launcher, close button, or Escape.

## Important options

| Prop                    | Default                 | Purpose                                                                 |
| ----------------------- | ----------------------- | ----------------------------------------------------------------------- |
| `editor`                | Required                | Supplies document state and selection to every turn.                    |
| `transport`             | Required                | Sends requests and conversation history to your route.                  |
| `open` / `onOpenChange` | Uncontrolled            | Lets your application own the open state.                               |
| `defaultOpen`           | `false`                 | Sets the initial state when it is uncontrolled.                         |
| `storageKey`            | `emend:ai-assistant:v1` | Use a unique key per document or workspace to separate browser history. |
| `policy`                | Adaptive scopes         | Restricts context and mutation choices in the chat composer.            |

## Behavior notes

- The welcome view puts the composer beneath “How can I help you today?” with
  quick actions for selected text below it. During a conversation, the composer
  docks at the bottom.
- The action menu offers **Improve**, **Shorten**, **Longer**, **Fix grammar**,
  **Tone**, and **Custom instruction**. Tone offers Friendly, Professional,
  Confident, and Straightforward styles. Built-in edits require selected text.
- **New chat** saves the current conversation and stops or dismisses its active turn.
- **Chat history** reopens the latest 20 conversations saved in this browser.
  Delete a saved chat with its delete button. Old turns are transcripts; old edit
  proposals cannot be applied again.
- Browser history has a total size budget of roughly 2 MB. Older chats are removed
  first when the budget is reached. If the current chat cannot be saved, the UI
  explains that it is available only in the current session.
- History uses local storage without encryption or server sync. Use a distinct
  `storageKey` for each document and signed-in user, and clear user-scoped storage
  during sign-out in your application.
- Follow-up requests include the visible conversation plus the new message, subject
  to the existing transport request limits.
- Ask answers stay informational. Edit turns retain Accept, Reject, and stale
  proposal checks before changing the document.

The old `@emend/ai-side-chat` registry name and `AiSideChat` export remain
compatibility aliases. Use `@emend/ai-assistant` and `AiAssistant` for new code.
