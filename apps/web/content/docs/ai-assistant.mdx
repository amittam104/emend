The AI Assistant is a chat window that opens from a button in the bottom-right
corner. It can see your document, so you can:

- **Ask questions** about what you wrote, and follow up like a normal chat.
- **Edit your text:** Select some text, pick an action or type what you want,
  and review the change before it is applied.

## Try it

Click the AI Assistant button in the bottom-right corner. Ask something about
the text, send a follow-up, or select some text and pick an action like
**Improve**.

## Before you start

This page assumes your app already has a Tiptap editor and you have completed
[Installation](/docs/installation). If you do not have an editor yet, use the
[Editor Starter](/docs/emend-editor-starter) instead. Its AI Assistant
version comes with the chat already set up.

## Add the AI Assistant

<Steps>
<Step>

### Install the component

```npm
npx shadcn@latest add @emend/ai-assistant
```

This copies the AI Assistant into `components/emend/ai-assistant` and installs
`@emend/ai` and the Tiptap packages it needs.

</Step>
<Step>

### Add it to your editor

Add the `EmendAi` and `Markdown` extensions to your editor, then render the
AI Assistant with that same editor.

```tsx title="components/document-editor.tsx"
"use client"

import { EmendAi } from "@emend/ai/tiptap" // [!code ++]
import { createFetchTransport } from "@emend/ai/transport" // [!code ++]
import { Markdown } from "@tiptap/markdown" // [!code ++]
import { EditorContent, useEditor } from "@tiptap/react"
import StarterKit from "@tiptap/starter-kit"
import { AiAssistant } from "@/components/emend/ai-assistant" // [!code ++]

const transport = createFetchTransport({ url: "/api/editor-ai" }) // [!code ++]

export function DocumentEditor() {
  const editor = useEditor({
    immediatelyRender: false,
    extensions: [StarterKit, Markdown, EmendAi], // [!code ++]
    content: "<p>Select this sentence and ask emend to improve it.</p>",
  })

  if (!editor) return null

  return (
    <div className="relative">
      <EditorContent editor={editor} />
      {/* [!code ++] */}
      <AiAssistant editor={editor} transport={transport} />
    </div>
  )
}
```

The `transport` tells the chat which URL to send AI requests to. The AI
Assistant adds its own button to the bottom-right corner of the page. Click it
to open the chat.

</Step>
</Steps>

## Open it from your own button

The AI Assistant always shows its own button in the bottom-right corner. To
open the chat from another button too, pass `open` and `onOpenChange`. The
install command adds the Shadcn `Button` used here if your project does not
have it yet.

```tsx title="components/document-editor.tsx"
"use client"

import { EmendAi } from "@emend/ai/tiptap"
import { createFetchTransport } from "@emend/ai/transport"
import { Markdown } from "@tiptap/markdown"
import { EditorContent, useEditor } from "@tiptap/react"
import StarterKit from "@tiptap/starter-kit"
import { useState } from "react" // [!code ++]
import { AiAssistant } from "@/components/emend/ai-assistant"
import { Button } from "@/components/ui/button" // [!code ++]

const transport = createFetchTransport({ url: "/api/editor-ai" })

export function DocumentEditor() {
  const [open, setOpen] = useState(false) // [!code ++]
  const editor = useEditor({
    immediatelyRender: false,
    extensions: [StarterKit, Markdown, EmendAi],
    content: "<p>Select this sentence and ask emend to improve it.</p>",
  })

  if (!editor) return null

  return (
    <div className="relative">
      {/* [!code ++:3] */}
      <Button type="button" variant="outline" onClick={() => setOpen(true)}>
        Open AI Assistant
      </Button>
      <EditorContent editor={editor} />
      <AiAssistant
        editor={editor}
        transport={transport}
        open={open} // [!code ++]
        onOpenChange={setOpen} // [!code ++]
      />
    </div>
  )
}
```

## Props

| Prop                    | Default                 | Purpose                                                                |
| ----------------------- | ----------------------- | ---------------------------------------------------------------------- |
| `editor`                | Required                | Your Tiptap editor.                                                    |
| `transport`             | Required                | Tells the chat which URL to send AI requests to.                       |
| `open` / `onOpenChange` | Not set                 | Control when the chat is open from your own code.                      |
| `defaultOpen`           | `false`                 | Whether the chat starts open.                                          |
| `storageKey`            | `emend:ai-assistant:v1` | Where chat history is saved. Use a different key per document or user. |
| `policy`                | Adaptive scopes         | Limits what the AI can read and change.                                |

To use the AI Assistant together with another AI component on the same editor,
use `AiAssistantView` with a shared session. See
[Use more than one AI component](/docs/existing-tiptap-editor#use-more-than-one-ai-component).

## How it behaves

- **Actions:** **Improve**, **Shorten**, **Longer**, **Fix grammar**, **Tone**
  (Friendly, Professional, Confident, or Straightforward), and **Custom
  instruction**. The built-in actions need selected text.
- **Questions:** Anything you type without an action is a question. The answer
  shows up in the chat and your document is not changed.
- **Edits:** These show a preview in your document with **Accept** and **Reject**
  buttons, just like the other components.
- **New chat** saves the current chat and starts a fresh one.
- **Chat history** shows your last 20 chats. You can reopen or delete them. Old
  chats can be read, but their edit suggestions can no longer be applied.

### Where chat history is saved

Chats are saved in the browser's local storage. They are not encrypted and are
not sent to your server.

- History is limited to about 2 MB. When it is full, the oldest chats are
  removed first.
- Use a different `storageKey` for each document and each signed-in user, so
  people do not see each other's chats.
- Clear the user's saved chats when they sign out.
