description: Copy a complete Tiptap editor with no AI or one of three reviewable AI surfaces.

Choose this path when you want a complete editor copied into your application.
The starter keeps the source editable and exposes the underlying Tiptap editor
through `onEditorReady`.

## Starter choices

- **AI Bubble Menu:** the default and smallest AI-first starting point.
- **No AI:** the editor, toolbar, formatting, and save boundary only.
- **AI Composer:** prompt and review controls below the document.
- **AI Side Chat:** document-aware conversation beside the editor.

<Callout type="warn" title="Preview package required">
  The three AI starters depend on the unpublished `@emend/ai` package. Their
  registry flow is verified with a packed package, but public installation will
  not complete until that package is released. The no-AI starter has no
  `@emend/ai` dependency.
</Callout>

## Install one starter

| Choice                   | Registry item                   | Export                |
| ------------------------ | ------------------------------- | --------------------- |
| AI Bubble Menu (default) | `@emend/emend-editor`           | `EmendEditor`         |
| No AI                    | `@emend/emend-editor-base`      | `EmendEditorBase`     |
| AI Composer              | `@emend/emend-editor-composer`  | `EmendEditorComposer` |
| AI Side Chat             | `@emend/emend-editor-side-chat` | `EmendEditorSideChat` |

Install only the choice you plan to ship. The default is:

```npm
npx shadcn@latest add @emend/emend-editor
```

The other choices use these exact commands:

### No AI

```npm
npx shadcn@latest add @emend/emend-editor-base
```

### AI Composer

```npm
npx shadcn@latest add @emend/emend-editor-composer
```

### AI Side Chat

```npm
npx shadcn@latest add @emend/emend-editor-side-chat
```

## Render the default starter

```tsx title="app/editor/page.tsx"
"use client"

import { createFetchTransport } from "@emend/ai/transport"
import { EmendEditor } from "@/components/emend/emend-editor"

const transport = createFetchTransport({ url: "/api/editor-ai" })

export default function EditorPage() {
  return <EmendEditor transport={transport} />
}
```

Omit `transport` only for `EmendEditorBase`. AI-enabled starters need a
transport before they render their AI surface.

## Keep access to Tiptap

Use `onEditorReady` when your application needs the underlying editor for save,
collaboration, analytics, or other extensions.

```tsx
<EmendEditor
  transport={transport}
  onEditorReady={(editor) => {
    editor.commands.focus()
  }}
/>
```

## Expected result

The selected registry item copies one editor foundation and only its chosen AI
surface. Continue to [Vercel AI Gateway](/docs/vercel-ai-gateway) to connect a
production route, or read the page for your chosen component.
