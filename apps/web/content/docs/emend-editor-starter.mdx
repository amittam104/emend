Use this guide if you do not have an editor yet. One command copies a complete
editor into your app, with a toolbar, formatting, tables, and saving. The code
is yours, so you can change anything.

## Pick a version

- **AI Bubble Menu (recommended):** select text and the AI menu opens next to
  it.
- **No AI:** just the editor. You can add AI later.
- **AI Composer:** a prompt bar under the document.
- **AI Assistant:** a floating chat panel over the editor.

## Install it

First complete [Installation](/docs/installation) to add the `@emend` registry
to `components.json`. The starter command
installs its Tiptap dependencies and the published AI runtime when needed.

| Choice                   | Registry item                   | Export                 |
| ------------------------ | ------------------------------- | ---------------------- |
| AI Bubble Menu (default) | `@emend/emend-editor`           | `EmendEditor`          |
| No AI                    | `@emend/emend-editor-base`      | `EmendEditorBase`      |
| AI Composer              | `@emend/emend-editor-composer`  | `EmendEditorComposer`  |
| AI Assistant             | `@emend/emend-editor-assistant` | `EmendEditorAssistant` |

Pick one and run its command:

Each variant has its own component file. Only the Bubble Menu variant installs
the folder-level `index.ts` export. Use the direct import for the variant you
installed:

```tsx
import { EmendEditor } from "@/components/emend/emend-editor/emend-editor"
import { EmendEditorBase } from "@/components/emend/emend-editor/emend-editor-base"
import { EmendEditorComposer } from "@/components/emend/emend-editor/emend-editor-composer"
import { EmendEditorAssistant } from "@/components/emend/emend-editor/emend-editor-assistant"
```

Import only the variant you installed. The examples below use the Bubble Menu
variant.

## Add it to a page

```tsx title="app/editor/page.tsx"
"use client"

import { createFetchTransport } from "@emend/ai/transport"
import { EmendEditor } from "@/components/emend/emend-editor/emend-editor"

const transport = createFetchTransport({ url: "/api/editor-ai" })

export default function EditorPage() {
  return (
    <EmendEditor
      transport={transport}
      initialContent={{
        type: "doc",
        content: [
          {
            type: "paragraph",
            content: [
              {
                type: "text",
                text: "Select this sentence and improve it with AI.",
              },
            ],
          },
        ],
      }}
    />
  )
}
```

The `transport` tells the editor which URL to send AI requests to. The No AI
version (`EmendEditorBase`) does not need one.

## Get the Tiptap editor

The starter is built on Tiptap. If you need the Tiptap editor itself, for
example to save content or add your own extensions, use `onEditorReady`:

{/* prettier-ignore */}
```tsx title="app/editor/page.tsx"
<EmendEditor
  transport={transport}
  onEditorReady={(editor) => { // [!code ++]
    editor.commands.focus() // [!code ++]
  }} // [!code ++]
/>
```

## What you should see

A full editor on your page. If you picked an AI version, select some text or
open the AI component and try it.
