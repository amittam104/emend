Use this guide if your app does not have an editor yet. One command copies a
complete editor into your app, with a toolbar, formatting, tables, and saving.
The code is yours, so you can change anything.

<include>../partials/nextjs-only.mdx</include>

## Before you start

Make sure your project has everything below before you add the starter.

- The `@emend` registry added to `components.json` (see
  [Tell Shadcn where to find emend](/docs/installation#tell-shadcn-where-to-find-emend))
- A server route for AI requests, such as `/api/editor-ai`, if you pick an AI
  version. The [server route section](#connect-the-server-route) shows how to
  add one.

You do not need to install Tiptap first. The starter command installs it for
you.

## Pick a version

The starter comes in four versions. They share the same editor and differ only
in how you use AI:

- **AI Bubble Menu (recommended):** Select text and the AI menu opens next to
  it.
- **No AI:** Just the editor. You can add AI later.
- **AI Composer:** A prompt box under the document.
- **AI Assistant:** A floating chat panel over the editor.

Pick one. You can try all four in the [demo](#try-all-four) below.

## Choose the toolbar size

The toolbar is compact by default. Set `toolbarVariant="classic"` for larger
buttons. It works the same way in every version.

```tsx
<EmendEditor transport={transport} toolbarVariant="classic" />
```

When the toolbar is wider than the editor, scroll it sideways with touch or a
trackpad, or use the arrow buttons at each end.

## Links

Select text and click **Link** in the toolbar or the selection menu. Enter a
URL and press **Enter** to add it. With nothing selected, you can also type the
link text, or the URL itself is used as the text.

Click an existing link to select it, then click **Link** to change the URL,
open it in a new tab, or remove it. Links do not open while you are editing.
URLs without a scheme, like `example.com`, get `https://`. Only `http`,
`https`, `mailto`, and `tel` links and relative paths are accepted.

## Images

Click **Insert image** to choose an image file or paste an image URL. You can
add alt text for screen readers. The image goes where your cursor was.

By default, a chosen file is embedded in the document as a `data:` URL. This
needs no server, and the image is saved and reloaded with the rest of the
content (JSON, HTML, or Markdown). It also makes the document bigger, so files
are limited to 2 MB and to PNG, JPEG, GIF, WebP, and AVIF.

For real hosting, pass `onImageUpload`. It receives the file and returns the
URL to insert. emend does not host images for you.

```tsx
<EmendEditor
  transport={transport}
  onImageUpload={async (file) => {
    const body = new FormData()
    body.append("file", file)
    const response = await fetch("/api/uploads", { method: "POST", body })
    if (!response.ok) throw new Error("Upload failed")
    const { url } = await response.json()
    return url
  }}
/>
```

If the upload throws, the error message is shown and nothing is inserted.

## Find and replace

Click **Find and replace** at the end of the toolbar. Type to highlight every
match, press **Enter** for the next match or **Shift+Enter** for the previous
one, and use **Replace** or **Replace all**. Press **Escape** or the close
button to clear the search.

## Mentions

Type **@** or click **Mention** in the toolbar to pick an item from a list.
The starter lists the emend components as examples. Pass your own items with
`mentionItems`, or an empty list to turn mentions off. Define the list outside
your component so the editor is not recreated on every render.

```tsx
const people = [
  { id: "ada", label: "Ada Lovelace" },
  { id: "grace", label: "Grace Hopper" },
]

<EmendEditor transport={transport} mentionItems={people} />
```

## AI toolbar buttons

The AI Assistant version has a toolbar button that opens the chat, and the AI
Composer version has one that shows or hides the composer. Set
`showToolbarAssistantToggle` or `showToolbarComposerToggle` to `false` to hide
them. The AI Bubble Menu appears when you select text, so it has no toolbar
button.

## Get the Tiptap editor

The starter is built on Tiptap. If you need the Tiptap editor itself, for
example to save content or add your own extensions, use `onEditorReady`. It
works the same way in every version.

{/* prettier-ignore */}
```tsx title="app/editor/page.tsx"
"use client"

import { createFetchTransport } from "@emend/ai/transport"
import { EmendEditor } from "@/components/emend/emend-editor/emend-editor"

const transport = createFetchTransport({ url: "/api/editor-ai" })

export default function EditorPage() {
  return (
    <EmendEditor
      transport={transport}
      initialContent={{
        type: "doc",
        content: [
          {
            type: "paragraph",
            content: [
              {
                type: "text",
                text: "Select this sentence and improve it with AI.",
              },
            ],
          },
        ],
      }}
      onEditorReady={(editor) => { // [!code ++]
        editor.commands.focus() // [!code ++]
      }} // [!code ++]
    />
  )
}
```

## Try it

1. Open the page you created. You should see the full editor with its toolbar.
2. If you picked an AI version, select some text or open the AI component, and
   ask for a change.
3. The suggested change shows up as a preview. Click **Accept** to apply it,
   or **Reject** to throw it away.

Next, read the page for the AI component you picked, or see
[Vercel AI Gateway](/docs/vercel-ai-gateway) to set up the server route for
production.
