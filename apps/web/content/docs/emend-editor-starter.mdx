Choose this path when you want a complete editor copied into your application.
The starter keeps the source editable and exposes the underlying Tiptap editor
through `onEditorReady`.

## Starter choices

- **AI Bubble Menu:** the default and smallest AI-first starting point.
- **No AI:** the editor, toolbar, formatting, and save boundary only.
- **AI Composer:** prompt and review controls below the document.
- **AI Side Chat:** document-aware conversation beside the editor.
