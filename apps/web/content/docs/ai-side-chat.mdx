AI Side Chat keeps a conversation beside the document. Each turn can Ask about
the draft or create an Edit proposal, while follow-ups carry the visible
conversation into the next request.

## Live mock demo

Select **AI chat** in the editor toolbar. Ask about the draft, send a follow-up,
or select text and choose an Edit action.

## Minimal usage

Use controlled state when another control opens the chat.

```tsx
import { useState } from "react"
import { createFetchTransport } from "@emend/ai/transport"
import type { Editor } from "@tiptap/core"
import { AiSideChat } from "@/components/emend/ai-side-chat"

const transport = createFetchTransport({ url: "/api/editor-ai" })

export function DocumentChat({ editor }: { readonly editor: Editor }) {
  const [open, setOpen] = useState(false)

  return (
    <>
      <button type="button" onClick={() => setOpen(true)}>
        Open AI chat
      </button>
      <AiSideChat
        editor={editor}
        transport={transport}
        open={open}
        onOpenChange={setOpen}
      />
    </>
  )
}
```

The editor passed to this component must include `EmendAi`. Set `inline` when
the chat should occupy a column inside your editor layout; otherwise it uses a
sheet.

## Important options

| Prop                    | Default         | Purpose                                                      |
| ----------------------- | --------------- | ------------------------------------------------------------ |
| `editor`                | Required        | Supplies document state and selection to every turn.         |
| `transport`             | Required        | Sends requests and conversation history to your route.       |
| `open` / `onOpenChange` | Uncontrolled    | Lets your application own the open state.                    |
| `defaultOpen`           | `false`         | Sets the initial state when it is uncontrolled.              |
| `inline`                | `false`         | Renders a layout panel instead of a sheet.                   |
| `policy`                | Adaptive scopes | Restricts context and mutation choices in the chat composer. |

## Behavior notes

- **New chat** clears the visible local conversation and stops or dismisses the
  current turn when needed.
- Follow-up requests include the visible conversation plus the new message.
- Ask answers stay informational. Edit turns expose proposal review in the
  assistant message.
- The component does not persist or encrypt conversation history. Add your own
  storage only when your product requires it.
