The AI Bubble Menu appears for a non-empty text selection. It offers AI edits
in a compact bar, shows the proposal inline in the editor, and keeps Keep and
Discard beside the selection.

## Live mock demo

Select the sentence in the editor. Choose a quick edit or describe your own
edit in the bar. Expand the arrow to see more actions.

## Minimal usage

Add `EmendAi` to the same Tiptap editor and pass that editor to the copied
component.

```tsx
import { EmendAi } from "@emend/ai/tiptap"
import { createFetchTransport } from "@emend/ai/transport"
import { Markdown } from "@tiptap/markdown"
import { EditorContent, useEditor } from "@tiptap/react"
import StarterKit from "@tiptap/starter-kit"
import { AiBubbleMenu } from "@/components/emend/ai-bubble-menu"

const transport = createFetchTransport({ url: "/api/editor-ai" })

const editor = useEditor({
  immediatelyRender: false,
  extensions: [StarterKit, Markdown, EmendAi],
})

return editor ? (
  <>
    <EditorContent editor={editor} />
    <AiBubbleMenu editor={editor} transport={transport} />
  </>
) : null
```

## Important options

| Prop         | Default  | Purpose                                                  |
| ------------ | -------- | -------------------------------------------------------- |
| `editor`     | Required | The existing Tiptap `Editor` instance.                   |
| `transport`  | Required | Sends typed Emend requests to your mock or server route. |
| `showReview` | `true`   | Shows inline proposal decisions in the Bubble Menu.      |
| `className`  | —        | Extends the copied component's outer surface.            |

## Behavior notes

- Quick actions include Improve, Shorten, Expand, Tone, and Grammar. The compact
  bar moves extra actions behind the arrow on narrow screens. Every action
  targets only the selected text.
- A custom instruction also edits only the selection.
- A completed proposal appears inline. Keep applies it; Discard removes it.
- A content-changing transaction makes an open proposal stale. The stale
  proposal cannot be accepted.
