When you select text, the Bubble Menu opens right next to it. Pick an action
or type what you want, and the AI's suggested change shows up in place. Then
click **Accept** or **Reject**.

## Try it

Select the sentence in the editor below. Pick an action like **Improve**, or
type your own request in the bar. Click the arrow to see more actions.

## Add it to your editor

Add the `EmendAi` and `Markdown` extensions to your editor, then render the
Bubble Menu with that editor. Lines marked with **+** are the ones to add to a
normal Tiptap editor.

```tsx title="components/document-editor.tsx"
"use client"

import { EmendAi } from "@emend/ai/tiptap" // [!code ++]
import { createFetchTransport } from "@emend/ai/transport" // [!code ++]
import { Markdown } from "@tiptap/markdown" // [!code ++]
import { EditorContent, useEditor } from "@tiptap/react"
import StarterKit from "@tiptap/starter-kit"
import { AiBubbleMenu } from "@/components/emend/ai-bubble-menu" // [!code ++]

const transport = createFetchTransport({ url: "/api/editor-ai" }) // [!code ++]

export function DocumentEditor() {
  const editor = useEditor({
    immediatelyRender: false,
    extensions: [StarterKit, Markdown, EmendAi], // [!code ++]
  })

  if (!editor) return null

  return (
    <>
      <EditorContent editor={editor} />
      {/* [!code ++] */}
      <AiBubbleMenu editor={editor} transport={transport} />
    </>
  )
}
```

## Props

| Prop         | Default  | Purpose                                                  |
| ------------ | -------- | -------------------------------------------------------- |
| `editor`     | Required | Your Tiptap editor.                                      |
| `transport`  | Required | Tells the menu which URL to send AI requests to.         |
| `showReview` | `true`   | Shows the Accept and Reject buttons in the menu.         |
| `className`  | -        | Adds your own classes to the menu.                       |

## How it behaves

- The actions are Improve, Shorten, Expand, Tone, and Grammar. On small screens,
  some of them move behind the arrow.
- Actions and typed requests only change the text you selected.
- The suggested change shows up in place. **Accept** applies it. **Reject**
  removes it.
- If the text changes while a suggestion is showing, the suggestion is out of
  date and can no longer be accepted. Run the action again.
