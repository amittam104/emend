# Package versioning

Only `@emend/ai` is published. The first preview is prepared directly as `0.1.0`;
future runtime changes use `pnpm changeset`, followed by `pnpm release:version`.
Review the resulting package version and changelog before publishing.

Changesets consumes its pending change files when versioning. Follow the
repository's file-deletion approval rule before running that command.

See [the release guide](../RELEASING.md) for verification and publishing.
